# The Olive Table

Premium Mediterranean restaurant landing page built with React + Vite.

## Run locally

```bash
npm install
npm run dev
```

Then open the local URL Vite prints (normally http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

## Notes
- This is a portfolio/demo concept.
- Food imagery is loaded from Unsplash URLs, so an internet connection is useful during development.
- Reservation UI is front-end only; it does not send real bookings.
